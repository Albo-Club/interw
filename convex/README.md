# convex/

Interw's backend: Convex queries, mutations, actions, HTTP routes and crons.
Shared helpers (guards, projectors, object store, prompts, model calls) live
in `lib/`; tests sit next to the module they cover (`*.test.ts`).

Nothing here is documented twice. Read, in this order:

- `_generated/ai/guidelines.md` — Convex's own rules, regenerated by
  `convex dev`; they override training data.
- `../CLAUDE.md` — access-control, model-output, pipeline and erasure rules
  every change here must follow, and the commands that must pass.
- `../KNOWN_ISSUES.md` — the traps, and why things are the way they are.
- `../TESTING.md` — how each surface is verified.
